# 3.0 Resource & System Management (Revised)

Based on the actual system implementation, including the newly added Content Moderation features and the Analytics/User Security dashboards shown in the screenshots.

| ID | Functional Requirement |
| :--- | :--- |
| **3.1** | The system shall provide a secure login interface restricted to Administrator accounts only. |
| **3.2** | The system shall allow the Admin to monitor and review all 3D Science models and tutorial videos uploaded by Educators via the Content portal. |
| **3.3** | The system shall allow the Admin to **Lock** inappropriate educator-uploaded content, which temporarily hides it from students but allows educators to edit and correct it. |
| **3.4** | The system shall allow the Admin to **Delete** (Remove) severely violating educator-uploaded content, leaving a restricted "tombstone" view for the educator that prevents any further modifications. |
| **3.5** | The system shall require the Admin to provide a specific "Admin Reason" when locking or deleting a resource. |
| **3.6** | The system shall strictly enforce moderation rules by automatically disabling all interaction features (share, like, recommend) for locked and deleted content across the platform. |
| **3.7** | The system shall display clear Moderation Alerts to Educators on their dashboard/library, showing the status (Locked/Removed) and the Admin's provided reason. |
| **3.8** | The system shall allow the Admin to view a comprehensive list of all registered user accounts, including their assigned Role (Student/Educator/Admin) and Account Status via the User Security portal. |
| **3.9** | The system shall allow the Admin to manually deactivate or delete registered user accounts to enforce platform security. |
| **3.10** | The system shall display an Analytics Dashboard providing high-level metrics, including total internal views, total registered students, total educators, and inactive users. |
| **3.11** | The system shall display analytical breakdowns on the dashboard, including a list of the most educator-recommended resources and the overall subject distribution of resources. |
